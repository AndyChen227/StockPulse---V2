# Project configuration / 项目配置

**English:** This directory groups safe, version-controlled setup inputs. `env.example` lists supported local environment variables without real values. `requirements/` contains locked dependency sets for base, AI, and PostgreSQL runtimes. Real `.env` files and credentials remain untracked at the repository root.

**中文：** 本目录集中保存可以安全纳入版本控制的配置输入。`env.example` 列出本地支持的环境变量，但不含真实值；`requirements/` 保存基础、AI 和 PostgreSQL 三组锁定依赖。真实 `.env` 和凭证仍放在仓库根目录，并且不受 Git 跟踪。
