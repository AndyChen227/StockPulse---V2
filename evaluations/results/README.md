# Evaluation results / 评估结果

[English](#english) · [简体中文](#简体中文)

## English

Each JSON file records one reproducible model evaluation, including dataset
identity, configuration, metrics, and individual errors. Filenames identify
the candidate model and evaluation version. Regenerate results through the
evaluation runner rather than hand-editing metrics.

---

## 简体中文

每个 JSON 文件记录一次可复现的模型评估，包括数据集身份、配置、指标和逐项
错误。文件名用于标识候选模型与评估版本。应通过评估运行器重新生成结果，
不要手工修改指标。
