# Evaluation results / 评估结果

**English:** Each JSON file records one reproducible model evaluation, including dataset identity, configuration, metrics, and errors. Filenames identify the candidate and evaluation version. Regenerate results through the evaluation runner rather than hand-editing metrics.

**中文：** 每个 JSON 文件记录一次可复现模型评估，包括数据集身份、配置、指标和错误。文件名用于标识候选模型和评估版本。应通过评估运行器重新生成结果，不要手工修改指标。
