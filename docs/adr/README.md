# Architecture decision records / 架构决策记录

**English:** ADRs preserve important decisions that should remain understandable after implementation changes. Use sequential names such as `0002-short-decision-name.md` and record context, decision, alternatives, consequences, and status. Do not rewrite accepted history; supersede it with a new ADR.

**中文：** ADR 用于保存即使实现变化后仍需理解的重要架构决策。文件按 `0002-short-decision-name.md` 形式顺序编号，并记录背景、决策、备选方案、后果和状态。不要改写已经接受的历史；应通过新的 ADR 取代旧决策。
