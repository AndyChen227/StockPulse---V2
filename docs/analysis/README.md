# Analysis documents / 分析文档

This folder defines the versioned analytical meaning behind Dashboard results. 本目录定义 Dashboard 结果背后的版本化分析含义。

| File | One-sentence purpose / 一句话用途 |
|---|---|
| `sentiment-evaluation.md` | Sentiment benchmark, metrics, and model selection / 情绪基准、指标和模型选择 |
| `topic-analysis.md` | Topic taxonomy and representative-message evidence / 话题体系和代表消息证据 |
| `anomaly-detection.md` | Historical baselines, thresholds, and explanations / 历史基线、阈值和解释 |
