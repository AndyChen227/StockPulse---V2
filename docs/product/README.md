# Product documents / 产品文档

This folder explains the product outcome and delivery state. 本目录说明产品结果和交付状态。

| File | One-sentence purpose / 一句话用途 |
|---|---|
| `project-plan.md` | Current milestones, remaining gates, and launch acceptance / 当前里程碑、剩余门槛和上线验收 |
| `project-history.md` | PR-by-PR engineering record and validation evidence / 按 PR 记录工程成果和验证证据 |
| `dashboard.md` | User interface behavior and paid-action safety boundary / 用户界面行为和付费操作安全边界 |
